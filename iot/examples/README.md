# Examples and Test Code

This folder contains example code, test programs, and older implementations for reference.

## ESP8266 Examples
- `esp8266/espnow_test/` - ESP-NOW protocol testing and examples

## Orange Pi Examples
- `orangepi/gateway/` - Original cat feeder gateway implementation (deprecated, replaced by shelter_gateway.py)
- `orangepi/gateway.py` - Old standalone gateway (deprecated)
- `orangepi/rtsp_server.py` - Old RTSP server implementation (deprecated)
- `orangepi/rtsp/` - RTSP streaming demo and examples
- `orangepi/tools/` - Helper scripts and utilities for demos

## Current Active Code
The actively deployed code is in:
- `../orangepi/shelter_gateway.py` - Current production gateway for shelter monitoring
- `../esp8266/shelter_node/` - Current ESP8266 node code
- `../esp8266/smart_cat_feeder/` - Smart cat feeder node code (if still active)

## Usage
These examples are kept for reference and testing purposes. Do not use them in production.
